# Part-Time Airforce replays

Tacview recordings of missions played on Part-Time Airforce (PTA), the Nuclear Option servers (dsc.gg/tomosnukes). Every mission
on the servers is recorded with NOBlackBox and uploaded here, one release per mission, and the Discord post for that
mission links to its file.

## Watching a replay

1. Open the release for the mission and download the `.zip.acmi` file under Assets.
2. Open it in Tacview (File > Open, or double click the file). The free version plays these files, and Tacview has the
   Nuclear Option map and models built in.
3. No Tacview? Go to https://tomosnuclearbombos.github.io/nuclear-option-viewer/ and drag the file onto the page.
   On a phone, tap CHOOSE REPLAY and pick the file. It plays in your browser on the real map.

The file name has the server, the date and time the mission started (Australian Eastern time) and the mission name.
Recordings do not include Steam IDs.
